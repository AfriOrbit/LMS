THE FILES
---------
NEW   src/app/setup/page.tsx
      Configuration diagnostic. Names which environment variables actually
      arrived in the deployed bundle, and flags wrong-shaped values.

EDIT  src/proxy.ts
      Was throwing on missing Supabase config, which returned 500 on every
      route including robots.txt. Now redirects to /setup instead. Also wraps
      the getClaims() network call so a Supabase blip degrades to logged-out

EDIT  README.md
      Your copy has UTF-16LE bytes appended to the end — a run of null bytes
      that makes git treat it as a binary file, so GitHub will not render it
      and diffs are useless. This is what PowerShell's `>>` operator does by
      default. This copy is clean UTF-8.
